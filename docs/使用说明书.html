业务联系单生成助手

简明使用说明 · 上传单据，核对信息，下载 Excel

这个程序能做什么？

从订舱委托书、入货通知或订舱确认中提取提单号、船名、航次、船期、箱量及类型、场站、目的港和起运港，并填入业务联系单 Excel 模板。提取结果可在下载前人工修改。

选择文件开始提取人工核对下载 Excel

如何使用

  1. 打开：在 Windows 电脑上双击 ASW-Contact-Sheet.exe，程序会自动打开浏览器页面。
  2. 选文件：上传同一票业务的订舱委托书、入货通知或订舱确认。只有一份也可以；每份文件不超过 12 MB。
  3. 选方式：“规则演示”无需联网或密钥；复杂版式、扫描版 PDF 可选“AI 提取”。然后点击“开始提取”。
  4. 核对：逐项对照原始单据，改正错误或补充空白。承运公司、合约可手填；揽货人、客服可从英文名下拉列表选择。
  5. 导出：点击“下载业务联系单 Excel”，打开下载的表格，再检查一次内容和版式。

处理下一票：点击文件名旁的 × 移除单份文件，或点击“清空已选文件”，再选择新文件。请勿把不同票的单据一起上传。

使用 AI 提取时

选择“AI 提取”后，页面才会显示设置。填写服务商提供的 base_url、api_key、model，点击“测试连接并保存”，成功后再开始提取。设置只在本次程序运行期间有效，重启后需要重新填写。

DeepSeek 配置示例：

base_url：https://api.deepseek.com
api_key：XXX（占位符，使用时在程序页面填写自己的密钥）
model：deepseek-flash / deepseek-v4-pro（二选一，以账号实际可用的模型名称为准）

配置名称可参考 DeepSeek 官方模型文档。

AI 提取需要联网，可能产生服务商费用；单据内容会发送到配置的 AI 服务。使用前请确认公司允许处理相关客户资料。AI 结果也必须人工核对。

使用提醒

  • 找不到的字段可保持空白，在核对页根据邮件或聊天记录补填，不要猜测。
  • 旧版 .doc、.rtf、.xls 文件在使用电脑上可能需要安装 Microsoft Office；PDF、DOCX、XLSX 不需要。
  • 关闭浏览器标签不等于退出程序。再次双击 exe 可重新打开页面；用完请点击网页右上角“退出程序”。
